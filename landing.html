VidVibes

VidVibes – Youtube comment sentiment analyzer
VidVibes is a web tool that analyzes YouTube videos to show how viewers feel about them. Simply enter a YouTube URL, and VidBies fetches the comments, classifying each as positive, neutral, or negative using a pre-trained NLP model. It calculates the overall percentage of each sentiment and displays the top 100 comments, giving a quick snapshot of audience reactions. The sentiment analysis model is still under development, so improvements are ongoing. Built with Python, Roberta for sentiment analysis, and web scraping techniques, VidVibes turns raw comment data into meaningful insights

🛠 Tech Stack
Programming & ML: Python, Scikit-learn (for sentiment analysis)
Data Scraping: BeautifulSoup, Requests
Web Development: Flask, HTML, CSS
IDE & Deployment: VS Code, Render

IPL insights

IPL Insights – Interactive Cricket Analytics Dashboard
IPL Insights is an interactive data analytics web application built using Streamlit, designed to explore and visualize Indian Premier League (IPL) match and player data. The app transforms raw cricket statistics into meaningful insights through intuitive dashboards and comparisons.
Users can analyze match trends, evaluate individual player performances, and perform detailed team-vs-team and player-vs-player comparisons. With a clean UI and interactive controls, IPL Insights makes cricket data exploration both accessible and engaging for analysts and fans alike.

🔍 Key Features
Match Analysis: Explore match-level statistics, outcomes, and trends
Player Analysis: Deep-dive into individual player performance metrics
Team vs Team: Compare team statistics across seasons and matches
Player vs Player: Head-to-head analysis for key player matchups

🛠 Tech Stack
Python
Streamlit (for interactive web app)
Pandas, NumPy, Matplotlib/Seaborn (for data processing & visualization)
